Projects

Selected coursework and implementation experiments in representation learning, retrieval, speech, and reinforcement learning.

01 · Metric learning

Identity recognition from eye movements

Compared participant classification with triplet-based embeddings on GazeBase eye-tracking recordings. The project adapts CNN, recurrent, and residual models to short gaze sequences, with supporting MNIST experiments in classification and retrieval.

Python · PyTorch · PyTorch Metric Learning · GazeBase

02 · Code retrieval

Natural-language code search with UniXcoder

Adapted UniXcoder retrieval experiments for Java and Python. Explored function and window embeddings, similarity aggregation, and length-based ranking analysis to study how code representation affects search.

Python · PyTorch · Transformers · UniXcoder

Source on GitHub ↗

03 · Audio

Two-speaker speech separation

Developed an audio-only, TDANet-style separator that recovers two speech signals from a single mixture. The implementation combines iterative multiscale processing, permutation-invariant training, and speech-quality evaluation components.

Python · PyTorch · torchaudio · Hydra · Asteroid

Source on GitHub (access required) ↗

04 · Audio generation

HiFi-GAN-style speech vocoding

Built a neural vocoder that converts mel spectrograms into speech waveforms. Combined periodic and multiscale discriminators with adversarial, feature-matching, and mel-reconstruction losses; added multi-GPU training support and audio reconstruction demos.

Python · PyTorch · torchaudio · Hydra · LJ Speech

05 · Reinforcement learning

Learning robot rewards from visual preferences

Explored vision-language feedback for robot learning in a partial reproduction of RL-VLM-F. Used Qwen2-VL image preferences to train reward models for Soft Actor-Critic, and analyzed Open Drawer and Soccer experiments in Meta-World. Further experiments are required.

Python · PyTorch · Meta-World · SAC · Qwen2-VL
